## [0.2.0] - 2026-08-19

### Changed

- The minimum supported PHP version is now 8.2 ([#1](https://github.com/hakonephp/middleware-dispatcher/pull/1)).
- `Dispatcher`, `RequestInterceptor`, and `ResponseHandler` are now readonly classes ([#1](https://github.com/hakonephp/middleware-dispatcher/pull/1)).
- The package now requires `hakone/untouchable-psr7` `^1.1` ([#1](https://github.com/hakonephp/middleware-dispatcher/pull/1)).
- GitHub source archives now exclude development files and only ship `LICENSE`, `README.md`, `composer.json`, and `src/` ([#1](https://github.com/hakonephp/middleware-dispatcher/pull/1)).
